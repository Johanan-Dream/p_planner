## 1. 기존 상태와 변경 범위

기존 버전은 브라우저 안의 규칙 기반 초안이었고 지도·OpenAI 호출이 없었다. 선택 장소를 첫 번째 빈 날짜부터 채워 첫날에 몰릴 수 있었다.

기존 4단계 입력·타코군·브라우저 입력 저장을 유지하면서 아래를 개선했다.

### P0

- 여행 일수에 맞춰 분산한 후 실제 Google 도보 경로 비용으로 날짜별 장소 조합과 순서를 조정한다.
- 장소별 지정 날짜·시간, 사용자가 설정한 체류시간, 하루 활동시간을 반영한다.
- 필수·날짜 지정 장소는 충돌하더라도 삭제하지 않는다. 여행 기간 밖의 지정일도 미배치 후보에 이유와 함께 유지한다.
- Google Places의 날짜별 운영시간이 있으면 우선 사용한다. 없으면 정규 주간 운영시간을 참고하되 임시 휴무 확인 경고를 표시한다.
- 휴무·종료시간·시간 중복·활동시간 초과를 경고한다. 제공되지 않은 입장 마감은 추정하지 않는다.
- 0–30 계획형, 31–70 균형형, 71–99 즉흥형, 100 완전 즉흥형을 구분한다.
- 100%는 필수 표시·지정 조건을 후보로 보관하고 사전 방문 일정을 강제로 만들지 않는다.
- 날짜별 Google 지도 이미지에 방문 순서 번호 버튼을 얹고 일정 항목과 선택·스크롤을 연동한다.
- Google Routes의 실제 도보 경로 선·거리·예측 시간을 표시한다. 좌표 간 직선을 실제 이동 경로로 대체 표시하지 않는다.
- 방문지 간 실제 도보 구간이 10km 이상이면 조합·순서 조정을 우선하고 불가능한 구간은 경고한다.
- Google 실패 시 임의 운영·이동 정보를 만들지 않고 오류/미연동을 표시한다. 이동시간을 모르면 자유시간도 확정 숫자 대신 확인 필요로 표시한다.

### P1

- 카테고리 필터, Google에서 실제 조회한 사진·저작자 표시·평점·주소·운영시간·지도 링크.
- 필수 지정, 활동시간, 장소별 체류시간 및 날짜·시간 설정.
- 선택적 추가 요청은 명시적인 AI 버튼에서만 OpenAI로 해석한다. 선택하지 않은 장소 추가와 여행 날짜 변경 등 허용하지 않은 응답은 차단한다.
- 근처 장소 후보는 별도의 제안이며 사용자가 확인 버튼을 누르기 전에는 일정에 넣지 않는다. 직선거리는 직선거리라고 표시한다.
- 확인되지 않은 사진·평점·예약 필요 여부·마감일은 추정하지 않는다.

### P2

- 블루·옐로 일관된 색상과 날짜별 여행 티켓 결과 화면.
- 기존 타코군과 단계별 안내, 무계획력별 설명, 선택 장소의 지역에 맞춘 루트 제목.

## 3. 실제 경로 및 시간 근거

### 3일 6곳 분산, 20% 계획형

| 날짜 | 방문 순서 | Google 도보 구간 |
| --- | --- | --- |
| 11/16 | 구로몬 시장 → 신세카이 | 1,594m / 1,348초 |
| 11/17 | 도톤보리 → 신사이바시 | 364m / 300초 |
| 11/18 | 오사카성 → 우메다 스카이 빌딩 | 5,308m / 4,438초 |

이 검증에서는 모든 연속 구간이 10km 미만이었다. 모든 사용자 조건에서 이를 보장하는 것은 아니며 불가능하면 경고한다.

### 한 날짜에 3곳을 지정한 API 검증

- 도톤보리 → 구로몬 시장: 824m / 693초.
- 구로몬 시장 → 신사이바시: 1,187m / 998초.
- Google 지도 이미지: HTTP 200, 62,462바이트.
- 순서를 신사이바시 → 구로몬 → 도톤보리로 바꾸고 마지막 체류를 120분으로 변경: 지도 요청 순서 갱신, 잔여 자유시간 511분 → 451분.
- Google의 경로는 방향에 따라 다르며 브라우저의 자동 최적화 순서는 위 API의 강제 순서와 다를 수 있다.

## 5. 미완료·미검증 및 다음 행동

1. **확인된 예약 마감·D-day, 최종 입장 마감:** Google Places 응답만으로 확정할 수 있는 정보를 확보하지 못했다. 현재는 확인 필요이며 D-day 숫자를 만들지 않는다. 다음 단계는 공식 예약/입장 공지의 날짜·출처를 검증해 반영하는 것이다.
2. **실제 휴무일 충돌:** 확정된 실제 휴무일 데이터가 없어 실장소 시나리오는 미실행. 합성 회귀 테스트의 PASS를 실장소 검증으로 주장하지 않는다.
3. **경로 범위:** 현재는 방문지 사이의 Google 도보 경로다. 숙소·공항 이동, 대중교통 경로, 실시간 교통·현장 통행 보장은 제공하지 않는다.
4. **지도 방식:** 서버 프록시 Google 정적 지도 이미지 + 실제 경로 선 + 상호작용 번호 버튼이다. Google Maps JavaScript SDK의 자유로운 드래그·확대 지도는 아니다.
5. **운영정보 확실성:** 정규 주간 운영시간은 미래 여행일의 임시 휴무나 예약 가능성을 보장하지 않는다. 개별 상점·시설의 입장 마감도 구역의 운영시간과 다를 수 있다.
6. **실서비스 오류:** 현재 Google/OpenAI 검증에서는 실제 오류가 없었다. 연결 실패 처리·미확인 이동시간 표시는 합성 회귀 테스트로 확인했으나 실제 계정 권한을 의도적으로 해제하는 테스트는 하지 않았다.
7. **검증 범위:** 브라우저 테스트는 한 번의 생성→지도 선택→시간 수정→순서 변경→재접속 흐름이다. 모든 장소 조합과 모든 날짜에 대한 완전한 검증은 아니다.
